# 行业背景

行业资料必须在每次报告时重新联网核对,不可复用旧结论。

## 1. 具身智能

关注与 VLink 真正相关的基础设施需求:

- 多模态传感器高吞吐、低延迟与零拷贝;
- 仿真、采集、回放、训练数据和现场诊断闭环;
- 边缘 GPU/CPU 异构部署、机器人本体网络与云端协作;
- 模型推理并不等于通信基础设施,VLink 的价值边界要写清。

优先引用主要机器人/仿真平台、开源项目、研究论文和官方技术资料。避免
用融资新闻或概念热度直接推导中间件采用。

## 2. 自动驾驶

分别分析研发工具链与量产运行时:

- 摄像头/点云/控制数据通道、录制回放、故障触发采集和可观测性;
- DDS/共享内存/车载网络、确定性、资源边界和跨平台;
- Autoware、Apollo 等生态的接口位置;
- 功能安全、网络安全、实时认证、长期维护与供应链要求。

没有 ISO 26262、ASPICE、ASIL、量产案例等公开证据时,只能写潜在适用或
差距,不得写成已满足。

## 3. ROS 2 与通信生态

至少核对报告当日受支持 ROS 2 发行版、RMW/DDS 现状、Zenoh 与共享内存
方向,并比较:

- ROS 2 提供的节点、执行器、参数、launch、包与社区生态;
- VLink 提供的通信模型、后端抽象、数据工具和部署能力;
- 二者是替代、旁路数据面、桥接、特定域补充还是独立体系;
- 接入 ROS 2 的技术成本、语义映射、性能收益和生态收益。

引用 ROS 2、各 RMW/中间件和相关项目的官方资料;发行版状态和 roadmap
属于时效事实,必须标日期。

## 4. 其他趋势

按实际关联度选择云边协同、软件定义汽车、数据闭环、Web 可视化、
MCAP/Rerun/Foxglove、容器/Kubernetes、AI 数据基础设施等背景。每一项
都要回答"为什么影响 VLink",无直接关系的热点不写入报告。
